# v0.4.3 — 修复"抓屏失败"（游戏已是无边框却抓不到）

依据用户日志与截图定位到真实原因，并修掉误导性提示；默认翻译热键改为 **Shift+F9**。

## 下载

| 文件 | 说明 |
| --- | --- |
| `SCTranslator-v0.4.3-win64.zip` | 解压到任意目录 → 双击 `SCTranslator.exe` |

## 真实原因（来自日志）

```
抓屏失败 {'left': 79, 'top': 555, 'width': 501, 'height': 314}:
Windows graphics function failed (no error provided): BitBlt
```

用户截图同时显示游戏**已经是 Borderless（无边框）**，而旧提示却让人"改成窗口化/无边框"——**提示是错的**。
真正原因：mss 走 **GDI BitBlt**，抓不动使用 **DXGI 翻转模型（flip model）** 的游戏画面。
这与是否独占全屏无关，无边框窗口同样会中招。

## 修复：抓屏多后端自动回退

| 顺序 | 后端 | 说明 |
| --- | --- | --- |
| 1 | **dxcam（DXGI 桌面复制）** | 专为抓游戏/全屏画面设计，实测 9–12 ms/帧（首次约 0.2 s 初始化） |
| 2 | mss（GDI BitBlt） | 普通窗口/桌面稳定，游戏画面可能失败 |
| 3 | Qt `QScreen.grabWindow` | 第三条独立路径，兜底 |

- **成功即记住**：下次优先用上次成功的后端（不会每次都先踩一次失败）
- 每个后端 2 次机会；**全黑画面**（HDR / 受保护内容常见）自动换下一个后端
- 抓屏区域自动**裁进虚拟桌面范围**（越界/负坐标不再直接失败）
- 新增 `--doctor` 自检项 **抓屏后端**：逐个试并报告谁可用，例如
  `当前使用 dxcam；dxcam 已安装=True；dxcam: 可用，mss: 可用，qt: 跳过（自检无 GUI）`
- 失败时的提示改为**说真话**：列出各后端的具体错误 + 区域尺寸坐标，并提示 HDR / 受保护内容等真实可能原因
- 日志新增：每次按键记录 `收到 WM_HOTKEY`，每次截图记录 `抓屏后端 xxx`

依赖新增 `dxcam`（Windows 专用，随包分发，整包仍约 330 MB）。

## 默认热键

| 功能 | 默认键 | 说明 |
| --- | --- | --- |
| 截图翻译 | **Shift+F9** | 原来默认 F9，容易被其它软件占用（占用时 Windows 不会把键给本程序） |
| 重新框选 | **F10** | 不变 |

热键设置仍是"点一下直接按组合键"，录入期间会自动注销全局热键。
