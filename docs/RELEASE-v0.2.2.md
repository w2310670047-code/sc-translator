## 输出勾选（本次重点）

回话区与「游戏聊天码」卡片各有一组复选框 「中文码」/「译文（英文）」，互不影响：

| 中文码 | 译文/英文 | 输出 | 需要 API |
| :---: | :---: | --- | --- |
| ☑ | ☐ | `[zh] @IH@E8@AP` —— **中译中**，只发中文，纯本地编码 | 否 |
| ☐ | ☑ | `How are you` —— **中译英**，只发外语 | 是 |
| ☑ | ☑ | `[zh] @IH@E8@AP` ↲ `[en] How are you` —— **同时翻译**，双方都看得懂 | 是 |

细节：

- **两项至少勾一个**：取消最后一个会自动勾回并在状态栏提示
- 回话区的「译文」跟随目标语言，标记随之变为 `[en]` / `[ja]` / `[ko]`
- 按钮文字随组合变化：`编码并复制` / `翻译为英文并复制` / `生成双行并复制`（回话区为 `翻译并复制`）
- 勾选状态落盘（`reply_out_code`、`reply_out_foreign`、`gamecode_out_code`、`gamecode_out_en`）；
  旧版 v0.2.1 的单一 `reply_dual_line=true` 会自动升级为"中文码 + 译文"都勾选
- 退化路径：没码表 → 提示装汉化；翻译失败或没填 Key → 至少把中文码行发出去，不发半成品
