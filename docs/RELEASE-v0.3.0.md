## 新增：界面语言切换

| 项 | 说明 |
| --- | --- |
| 位置 | 顶栏右下角下拉框（界面语言 / 介面語言 / Language） |
| 语言 | 简体中文 · 繁體中文 · English |
| 生效方式 | **立即重建界面**，无需重启；窗口尺寸位置保留 |
| 记忆 | 写入 `data\settings.json` 的 `ui_language`，下次启动直接使用该语言 |
| 忙碌保护 | 翻译进行中拒绝切换并在状态栏提示（避免回调打到已销毁控件） |

实现方式（`sc_translator/i18n.py`）：

- **一条 key 一行三语**，用元组存放：`"status.ready": ("就绪", "就緒", "Ready")`
  —— 结构上不可能漏翻，新增文案只加一行；
- `t(key, **占位符)` 取值并格式化，缺失时回退简体中文、再回退 key 本身，**永不抛异常**；
- 服务商下拉的显示名跟随语言，**存进设置的值始终是稳定 key**（`DeepSeek`/`OpenAI`/`custom`），
  旧版把显示名存进设置的会**自动迁移**；
- 启动最早阶段就设定语言，连"已在运行 / 启动失败"这类启动期对话框也是用户选择的语言。

`tests/test_i18n.py`（12 项）守住底线：三语齐全、英文文案里不许出现中文、繁中必须确实不同于简中、
占位符格式化、缺失 key 优雅回退、切语言重建窗口并落盘、忙时拒绝切换、服务商稳定 key 与旧值迁移。
