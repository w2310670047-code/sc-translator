# v0.4.9 — 修完 4 个用户反馈的 bug，并加上 GPU 加速 / 模型直接读图 / 设置对话框

这一版把用户实测反馈的 4 个问题都修了（其中两个是同一个根因），另外按需求新增了 GPU 加速、
「模型直接读图」两种识别方式，并把"配好就不动"的设置收进右上角齿轮对话框。

## 下载

| 文件 | 说明 |
| --- | --- |
| `SCTranslator-v0.4.9-win64.zip` | 解压到任意目录 → 双击 `SCTranslator.exe` |

> 本版**已内置 DirectML 运行时**（`DirectML.dll`，约 18 MB），所以「GPU 加速」开箱可用。

## 修复（用户反馈）

| # | 反馈 | 根因（实测确认） | 修复 |
| --- | --- | --- | --- |
| 1 | 打开鼠标穿透后**回话功能失效** | 穿透用的是**整窗** `WS_EX_TRANSPARENT` + `WA_TransparentForMouseEvents`，窗内所有控件一起收不到鼠标 | 改为**逐区域命中测试**：自己回答 `WM_NCHITTEST`，译文滚动区与回话输入条归浮窗，其余区域返回 `HTTRANSPARENT` 交给下面的游戏 |
| 2 | 打开鼠标穿透后**无法滚动** | 同上 | 同上（滚动区进入可交互区域） |
| 3 | 第 3 次翻译后**一直卡在"正在识别并翻译"** | `TranslationCache.put()` 持着锁调用 `flush()`，而 `flush()` 又要拿同一把**不可重入**锁 ⇒ 第 25 次写入（每 25 次自动落盘）**自我死锁**，工作线程永久卡住 | 落盘移到**锁外**；`flush(timeout=...)` 支持限时取锁 |
| 4 | 关闭软件时显示 **"Python 未响应"** | 与 #3 **同一根因**：关窗时 `shutdown() → cache.flush()` 抢同一把被卡死的锁 ⇒ 主线程冻结 | 同 #3，且退出落盘改为 **2 秒超时**（宁可丢一次缓存也不冻住界面） |

> 附带修掉一个由真机复核抓出的隐藏 bug：**"回话条一开就强制固定"**会把用户刚打开的「鼠标穿透」立刻改回去
> （表现为"穿透开关点了等于没点"，浮窗「取消固定」同样失效）。

## 更快（实测数字）

| 改动 | 实测效果 |
| --- | --- |
| 不再每按一次热键就重新探测 `/models` 并重建 TLS 连接（进程级前缀缓存 + 共享 Session） | 省 **2~4.5 秒/次**（日志实测 4395ms、1960ms） |
| OCR 检测尺寸按框选大小优化（`det_limit_side_len` 736 → 512；默认会把短边放大到 736） | 单帧 OCR **0.72~0.78 s → 0.47~0.48 s（−38%）**，识别结果一致 |
| 同一画面重复按键直接复用上次结果（帧哈希） | **0.005 s**（哈希本身约 0.6 ms） |
| 分阶段反馈：识别完先显示原文，译文回来原地替换 | 等待从"一片安静"变成"立刻有反馈" |

## 新增

| 功能 | 说明 |
| --- | --- |
| **GPU 加速（DirectML）** | 设置里可切。实测 OCR **0.48 s → 0.09 s（约 5.2 倍）**；显存固定 **+约 210 MB**、120 次推理不增长，关掉后**回落到基线**。需要 `onnxruntime-directml`（打包版已内置） |
| **模型直接读图** | 设置里可切：把框选的小图**直接交给多模态模型**（如 `deepseek-flash`）一次完成识别+翻译，**不吃本机 CPU/显存**。**注意：截图会上传服务商**，并按图片 token 计费（官方上限 1024/张，用 `detail=low` 缩到 512） |
| **浮窗标题栏「穿透」按钮** | 在浮窗里就能切穿透/固定，与主窗口勾选双向同步 |
| **设置对话框**（右上角 **⚙ 设置**） | 服务商/API Key/模型、SC 术语表、截图热键、OCR 加速与读图、结果去哪里、译文浮窗、界面语言与日志全部收进去；主界面只留翻译与截图触发 |
| 截图结果**自动贴到最新一行** | 旧实现取到的是布局前的旧滚动范围，永远"差一屏" |

## 升级提示

- **源码运行**想用 GPU：`pip install --force-reinstall --no-deps onnxruntime-directml`
  （`pip list` 里可能同时有 CPU 版与 directml 版，谁最后落盘谁生效；用 `python -c` 打印 providers 确认列出
  `DmlExecutionProvider` 才算成功）。不装也不影响：界面开关会自己退回 CPU 并说明原因。
- **模型直接读图**会把截图发到你的服务商，请按需开启；关闭后完全回到本地 OCR。
- 设置与数据仍在程序目录下的 `data\`，**覆盖升级不会丢设置**（`bootstrap` 只在文件缺失时释放提示词与术语表）。

`截图翻译：N 行，抓屏后端 ...，OCR ...ms，翻译 ...ms，合计 ...ms`）与 `data\logs\startup.log`。
