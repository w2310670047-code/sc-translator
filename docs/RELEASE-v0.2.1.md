## 新增：回话双行开关

回话区新增复选框 **「双行：中文码 + 译文」**：

| 开关 | 输出 | 谁看得懂 |
| --- | --- | --- |
| **开**（同时翻译为中文与英文） | `[zh] @IH@E8@AP`<br>`[en] How are you` | 中国玩家看第一行、外国玩家看第二行 |
| **关**（默认，只翻译为外语） | `How are you` | 只有外国玩家 |

- 第一行是**中文游戏码**（利用游戏本地化 `@KEY` 展开语法，见 v0.2.0 说明），点一次
  「翻译并复制」即可同时得到两行，进游戏直接 `Ctrl+V`
- 目标语言选日语/韩语时标记随之变为 `[ja]` / `[ko]`，第一行仍是中文码
- 本机没有汉化码表时，开启双行会**自动退回"只输出译文"**并在状态栏提示（不会发出半成品）
- 开关状态写入 `data\settings.json`（`reply_dual_line`），下次启动保持

## 实测

```text
输入「你好吗」（开关开，目标 English）
 -> [zh] @IH@E8@AP
    [en] How are you          （已自动复制到剪贴板）

输入「你好吗」（开关关）
 -> How are you
```
