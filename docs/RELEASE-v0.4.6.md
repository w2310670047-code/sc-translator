## 新增：常驻译文悬浮窗（0.4.0 下线后重新上线）

- **累积历史**：`Shift+F9` 截图翻译的结果进一个置顶浮窗，**同一句只占一行**（同文原地更新，不重复占行），
  上限 `max_entries`（默认 120，超出滚动）；不再依赖已删除的实时巡逻管线。
- **两态交互**：未固定时整窗**鼠标穿透**（游戏内不挡操作）；点边缘「☰ 固定」即可交互——拖动标题栏移动、
  右下角缩放、右键菜单、点「取消固定」回到穿透态；位置与穿透状态持久化。
- **回话输入条**：勾选后可直接在浮窗里输入中文回话（Enter 翻译），问答记录保留最近 8 条；
  译文是否自动进剪贴板由「回话译文自动复制」开关决定。
- **复制全部**：一次把所有译文写进剪贴板（正文也可选中局部复制）。
- **隐藏与找回**：点「✕」隐藏；主窗口截图卡片里的「显示浮窗」随时叫回来。
- **三语**：浮窗文案全部走 i18n，切换界面语言即时生效（旧版浮窗是硬编码中文）。

## CPU 亲和规则（按你的要求重写）

- 有大小核 → **固定 1 个小核**（EfficiencyClass 最小者）；
- 无小核 → **最多 2 个逻辑处理器，且来自不同物理核**（绝不取同一物理核的两个超线程）；
- **任何情况下都不等于整机掩码**（严禁占用整个 CPU）：整机逻辑核数不超过限额时宁可放弃绑定。

> 注意：该模块**目前仍无调用点**（`pin_single_core` 设置也无人读取），所以这条规则暂时不会作用到运行中的程序。

```text
冷启动            0.76 s / 0.96 s（与文档"约 1 秒"一致）
空闲 CPU          0.00%（静置 8 秒、不按任何热键）
空闲内存          WS ≈ 150 MB（Qt 进程 145~151 MB）/ Private ≈ 85 MB
单次 OCR          热态 0.68 s（760×200 小区域）；首次含模型加载 1.82 s
按过一次热键后     +约 90 MB 常驻（OCR 模型加载后不释放，这是刻意的）
```
