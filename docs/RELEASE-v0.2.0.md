## 新增：游戏聊天码（中文 ⇄ 游戏内 `@码`）

星际公民聊天框打不了中文，但游戏本地化语法 `@KEY` 会展开成该键的值。
社区把 7020 个常用汉字注册成游戏 `global.ini` 里的本地化键（键名 = 汉字序号转 base36），
聊天里只发 `@IH@E8@AP`，客户端就渲染成「你好吗」。

本版本把这条链路做进了工具：

- **编码**：输入中文 → 即时得到 `[zh] @IH@E8@AP` → 自动复制 → 游戏内 `Ctrl+V` 发送
- **解码**：别人发来的 `[zh] @…` 粘进来 → 一键还原成中文（社区原工具没有反向功能）
- **码表自动检测**：直接读本机已装汉化的
  `…\StarCitizen\LIVE\data\Localization\chinese_(simplified)\global.ini`，
  也可手动指定；状态栏显示码表字数与版本
- **解码防误伤**：严格遵循编码器不变式（码后必接空格），`@Bob` 这类玩家名不会被拆成汉字
- **依赖说明**：需已安装带「社区输入法支持」的汉化；未安装时功能给出提示，不影响翻译主功能

实测（本机真实汉化，码表 7020 字 / 版本 0.0.1）：

```text
你好吗            -> [zh] @IH@E8@AP            -> 你好吗
走，去斯坦顿星系   -> [zh] @F8 ， @57@0HT@MD@05J@XB@JF  -> 走，去斯坦顿星系
Pyro 见 @Bob      -> [zh] Pyro @31 @Bob        -> Pyro 见 @Bob
```

## 已知限制

- 码表仅覆盖 7020 个常用汉字，未覆盖的字会被丢弃（与原社区实现一致）
- 编码/解码依赖双方安装同款汉化；`[zh]` 前缀只是社区约定
- 术语表里官方整句条目按整句匹配；`Area18` 这类无空格写法需自行补充
