## 新增：CPU 亲和开关（主窗口「截图翻译」卡片）

勾上 **「限制到单个小核」** 后，整个程序（含截图翻译的 OCR）会被绑定到 **1 个小核/效率核** 上，
尽量不和游戏抢大核；取消勾选立即恢复全部逻辑核，无需重启。

| 规则 | 行为 |
| --- | --- |
| 有大小核（如 Intel 12 代及以后） | 固定 1 个 **E-core**（EfficiencyClass 最小者） |
| 没有小核（普通 CPU） | 最多占 **2 个逻辑处理器**，且来自**不同物理核**（绝不取同一物理核的两个超线程） |
| 任何情况 | **绝不等于整机掩码**（严禁占用整个 CPU）：整机逻辑核数不超过限额时宁可不绑定 |
| 边界 | 取不到拓扑信息 → 退回"编号最低的单个逻辑核"；失败只记日志，不影响使用 |

**取舍（重要）**：绑定后 OCR 只能在单核上跑，**截图翻译会变慢**（换来的是不与游戏抢核）。
所以该开关**默认关闭**，按需勾选。

实测（本机 i5-14600KF，6P+8E / 20 逻辑核）：

```text
勾选前  进程掩码 0xfffff  逻辑核 [0..19]
勾选后  进程掩码 0x1000   逻辑核 [12]        <- 小核(E-core)
取消后  进程掩码 0xfffff  逻辑核 [0..19]     <- 全部恢复
```

同时修掉一个**静默 bug**（v0.4.6 已修解析、本版才真正生效）：`GetLogicalProcessorInformationEx`
的 `GroupMask` 偏移算错（早 3 字节），导致每个核的掩码混入一个假 bit 8，"固定小核"实际固定到了大核。

## 新增：浮窗与截图旋钮全部做成控件

以前这些值只能改 `data\settings.json` 再重启；现在都在界面上，**改动即时生效并落盘**。

主窗口新增一张 **「译文浮窗」卡**（并把原先散在截图卡里的浮窗选项一并归置过来）：

| 控件 | 设置项 | 默认 | 作用 |
| --- | --- | --- | --- |
| 常驻显示 | `always_show` | 开 | 关掉则只在有新译文时出现（配合「空闲淡出」） |
| 空闲淡出(秒) | `auto_hide_sec` | 0 | 0=不自动隐藏；**仅在未勾选「常驻显示」时生效** |
| 保留行数 | `max_entries` | 120 | 浮窗历史行数上限，超出淘汰最早；**调小立即裁剪** |
| 字号 / 不透明度% | `font_size` / `opacity` | 14 / 92 | 浮窗外观，改了**立即重刷** |
| 显示原文 | `show_original` | 开 | 每行是否同时显示原文；**已有行立即重渲染** |
| 鼠标穿透 | `click_through` | 开 | =未固定态；与浮窗里的「固定」按钮**双向同步** |
| 回话输入条 / 回话译文自动复制 / 显示浮窗 | `reply_enabled` / `auto_copy_reply` | — | 从截图卡挪到本卡 |

截图翻译卡也补了两项：

| 控件 | 设置项 | 默认 | 作用 |
| --- | --- | --- | --- |
| 单次最多行数 | `snap_max_lines` | 40 | 一次截图最多送几行去翻译，防"误框整屏"烧 token |
| 结果写入主窗口 | `snap_write_main` | 开 | 两个浮窗都关掉时，它是结果的唯一出口 |
